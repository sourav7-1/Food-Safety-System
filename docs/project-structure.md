# Smart Street Food Safety Inspection and Risk Analysis System

Initial Flask project structure:

- `app.py`: Flask application entrypoint and app factory
- `config.py`: environment-based Flask and MySQL configuration
- `database/`: SQL scripts, migrations, or database notes
- `models/`: SQLAlchemy models
- `routes/`: Flask blueprints and route modules
- `services/`: business logic and risk analysis services
- `templates/`: Jinja2 templates
- `static/`: CSS, JavaScript, images, and other public assets
- `docs/`: project documentation
